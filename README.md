# Schmidt Coating · Tilbud fra C Studio

Statisk tilbudsmateriale til Thomas Schmidt, Schmidt Coating.

| Fil | Indhold |
|---|---|
| `index.html` | One-pager med tilbuddet |
| `deck.html` | Deck med nulpunkt, Fase 1, værdi, muligheder, annoncering og næste skridt |
| `assets/cstudio.css` | Fælles C Studio-stylesheet (farver, typografi, komponenter) |
| `assets/*.png` | C Studio-logoer (wordmark og signatur, lys og mørk) |

## Udgiv med GitHub Pages

1. Opret et nyt repository, fx `schmidt-coating-tilbud`.
2. Upload hele mappens indhold til roden af repoet.
3. Gå til **Settings → Pages**, vælg branch `main` og mappen `/ (root)`.
4. Siderne ligger derefter på `https://<brugernavn>.github.io/schmidt-coating-tilbud/` (one-pager) og `…/deck.html` (deck).

Siderne har `noindex`, så de ikke bliver fundet via Google. Bemærk at et offentligt repo kan ses af alle med linket.
